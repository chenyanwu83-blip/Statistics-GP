# R 分析脚本

## 负责人

各成员维护各自脚本，C 维护数据准备并负责最终合并。

## 用途与状态

以项目根目录为工作目录。01_C_data_preparation.R 是已实现的 C 数据准备试用脚本；02–06 当前为待填写任务骨架，不能视作已完成分析。D/E先运行数据准备，再使用qq_work。

## 协作约定

代码或文件存在不代表任务完成。数据规则变更须通知相关成员，重跑受影响分析并更新报告数字。

## C 数据准备入口

[01_C_data_preparation.R](01_C_data_preparation.R)

在项目根目录运行：

```r
source("scripts/01_C_data_preparation.R")
```

运行后原始对象为qq_raw，分析工作对象为qq_work，并生成试用数据和质量记录。
